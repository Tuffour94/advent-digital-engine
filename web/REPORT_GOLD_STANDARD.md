# ADE — Gold Standard Digital Audit Report (v1.0)

**Purpose**
- Understandable in under 2 minutes
- Trusted by non-technical leaders
- Consulting-grade (McKinsey/Bain feel)
- Shareable with boards/pastors/donors
- Never feels like a dev tool

## 1) Executive Header (Above the fold)
- Large score + grade badge
- 2–3 sentence executive summary
- Light benchmark context

## 2) Wins / Risks Panel
- Top 3 Wins (concrete)
- Top 3 Risks (never empty)
  - Include “soft risks” from score gaps

## 3) Recommended Next Steps (Pastor language)
Format each as:
- ✅ Action
- 📍 Where
- 🛠 How
- + Priority / Effort / Impact

## 4) Category Breakdown
- Wide rounded blue bars
- Weight + score visible
- All core categories present

## 5) Pages Checked (Audit trail)
- Status badge
- Title
- URL
- Category tag

## 6) Evidence Appendix
- Grouped by category
- Deduped
- Highlighted snippets
- Detected / Weak / Missing labels

## 7) Share / Export
- Copy link (real clipboard + “✓ Copied”)
- Print
- No broken UX

## 8) Advanced Mode (Hidden)
- Raw JSON / debug only behind toggle
- Owner/admin only

## 9) Scan History
- No scary legacy failures
- Clear history button
- Clean rows only

## 10) Design & Tone
- Clean, calm, professional
- No dev jargon (no tokens/artifacts/cache/debug)

## North Star
If a pastor screenshots this and sends it to a board member, it should look like a consulting report — not software.

## Release Gate
Not shippable unless:
- ✓ Summary
- ✓ Risks
- ✓ Clear steps
- ✓ Evidence
- ✓ No debug
- ✓ Copy works
- ✓ Strong hierarchy
